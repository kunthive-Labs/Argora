Find the businesses the web forgot.

Argora scans Google Maps for local businesses that have no real website, ranks them by conversion potential, and writes the outreach for you.

View on GitHub Run it locally

A business with no website, whose competitors have one, is the strongest lead there is.

That is the whole premise. Every city is full of driving schools, gyms, preschools, and law offices that run on word of mouth while their competitors rank on Google. Finding them by hand means hours of scrolling Maps and copying phone numbers into spreadsheets.

Argora automates the entire funnel: it finds those businesses, verifies that the "website" isn't just an auto-generated placeholder page, scores each lead across five dimensions, and produces a pitch that names the exact competitor already outranking them. No Apify credits, no Google Places API. Just Playwright and a database you own.

One pipeline, from map to message.

The scraper is replaceable. The intelligence is the product.

no-website detection

Placeholder pages don't fool it

Auto-generated Google Sites and business.site pages correctly count as "no website", because they are. Those are the strongest leads, not false negatives.

competitor matching

Every pitch names the competitor

Each lead is paired with a same-category business that does rank, so the message writes itself: your competitor is online, and you are not.

outreach studio

Ready to send, per channel

WhatsApp, call script, email, or walk-in brief, generated per lead with hot, warm, cool, and cold tiers so you work the list top down.

database of record

A lead can never be added twice

Generated SQL is guarded four ways against duplicates and verified end to end against Postgres 16. KunthiveOS stays the system of record; Argora fills it.

web app + cli

Watch the scrape live

A single-file, no-build UI streams every run over server-sent events. The same engine is scriptable from the command line.

sector presets

Trades that actually buy websites

Editable presets for driving schools, preschools, gyms, real estate, and law practices, plus a page extractor that transcribes a competitor's pricing page.

Running in two minutes.

Python 3.10 or newer. The web app opens your browser at localhost:8000 and streams the run as it happens.

argora - zsh
$ git clone git@github.com:kunthive-Labs/Argora.git && cd argora $ python3 -m venv .venv && source .venv/bin/activate $ pip install -r requirements.txt && playwright install chromium $ python app.py # or headless: python run.py driving-school "Jayanagar, Bengaluru"

Deliberately restrained.

Scraping tools usually race to evade detection. Argora refuses to. The restraint is the point: it keeps the tool legal to run, the data defensible, and the outreach welcome.

No evasion tooling

No CAPTCHA solvers, no proxy rotation, no login automation. Small, headed, spaced-out runs that behave like a person browsing.

Data stays local

Scraped business details are treated as PII. Outputs are git-ignored and live on your machine and in your own database, nowhere else.

Outreach stays legit

Messages respect India's TRAI and DND anti-spam rules. The goal is a first conversation, not a broadcast blast.
